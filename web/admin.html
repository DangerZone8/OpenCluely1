Important distinction

Cloud settings vs. app updates

This dashboard can roll out feature flags and settings immediately to compatible installed clients. It cannot safely replace executable application code. Binary updates continue through the signed desktop updater feed and require a published, verified build. A minimum-version setting can prompt users to update; it does not silently install unverified code.
