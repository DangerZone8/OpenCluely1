05 / Questions

Before you install.

Which operating systems are supported?

Slickly publishes desktop builds for Windows, macOS and Linux. The download section lists the installers available in the latest release.

Do I need to provide an API key?

No key is required to try the hosted AI service. You can optionally configure your own Gemini API key in the app. Hosted service availability and usage limits apply.

Can I ask follow-up questions about a screen?

Yes. Screen context is intended to carry into follow-up questions, so you can ask for an explanation or a next step without restating everything visible.

What happens to the content I submit?

Text, screen frames and audio you choose to submit are sent to the Slickly service and Google Gemini over HTTPS when using hosted AI. Avoid sending passwords, private keys or other sensitive information.

Where can I inspect the source?

Slickly is open source. The repository, issue tracker and release history are available on GitHub.
