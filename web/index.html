Open source · Desktop · Cross-platform

Your coding practice, with an AI companion.

OpenCluely is a desktop AI assistant designed to support coding practice, problem-solving, and learning. Review the source, configure your AI provider, and use it in line with the rules of your class, assessment, or workplace.

Get the latest release View source on GitHub

Desktop app, not a browser app

This site is the web landing page. The full application uses Electron and operating-system capabilities such as desktop windows, audio input, and screen capture, so those features run in the installed desktop app rather than inside Vercel.

Open source and configurable

Read the setup instructions, inspect the code, and configure supported AI and speech providers in the repository documentation.

AI-provider usage may require your own API key. Follow the rules and policies that apply to your learning or work environment.
